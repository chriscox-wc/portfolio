EXPERIMENT 02

A little order
from a little chaos.

Insertion sort builds a sorted section one value at a time. Watch each comparison, swap, and decision happen.

Sorted section Comparing or swapping
See the C++ idea +
for (int i = 1; i < n; ++i) {
  int j = i;
  while (j > 0 && a[j - 1] > a[j]) {
    swap(a[j - 1], a[j]);
    --j;
  }
}

The browser runs a JavaScript version of this algorithm. Worst-case time: O(n²). Best-case time: O(n).
